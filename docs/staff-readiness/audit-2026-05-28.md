9. **⚠️ 345 «dead files» + 6 sirkulære avhengigheter** (`audit-v4.mjs`, score 75/100).

### Tag-disiplin — kilde

`docs/FULL_PACKAGE.md` §2 «TAG + RELEASE NOTES»:

```markdown
### Tag-eksempler
- v3.1.0-wow
- rc-wow-YYYY-MM-DD
```

Dette er **release/RC-tags**, ikke semver `v{major}.{minor}.{patch}` strict — men en dokumentert release-konvensjon.

**Parallell udokumentert konvensjon i bruk:** `chore/sprint-ab-fase-*-complete` / `*-pre-backup` (15 tags, 2026-05-28). Disse er sprint backup-milepæler, ikke releases.

**Foreslått tillegg i `FULL_PACKAGE.md` §2 (dokumentasjon only — ikke implementert):**

### Release-tags (prod/RC)
- v{major}.{minor}.{patch} eller rc-wow-YYYY-MM-DD

- chore/sprint-{id}-fase-{letter}-complete
- chore/sprint-{id}-fase-{letter}-pre-backup

## Fase 2 — Umbraco (lunchportalen.no)

**Estimat Staff-grade (denne fasen):** ~72 %  
**Verifisert:** 2026-05-28 via repo, `az` CLI, `dotnet build`, HTTP mot prod

### Oppsummering — 5–10 viktigste funn

1. **✅ Media Blob + deploy-determinisme (F.X.3 / F.X.7)** — Azure Blob aktiv; V.27 stop→zip→start; `clean:true` trygt post-Blob.
2. **✅ uSync baseline i Git** — 234 filer under `uSync/v17/`; schema-only handlers (content/media disabled).
3. **⚠️ `ImportAtStartup: None`** — schema i Git, men ingen tvungen import ved deploy; drift mot DB mulig uten manuell import.
4. **❌ Secrets i klartekst** — `HMACSecretKey` **committet** i `appsettings.json`; `UnattendedUserPassword` i Azure App Settings (navn bekreftet, verdi ikke logget).
5. **❌ SKU Basic B1** — `alwaysOn: false`, ingen deployment slots, ingen health check path.
6. **⚠️ og:image / favicon fallback `zkhfkr4f` → 404** — hardkodet fallback i `_Layout.cshtml`; prod forsiden bruker CMS-media (`jhifs4zf` → 200) men fallback er død.
7. **⚠️ Razor nullable warnings** — clean build: **43 CS86xx** (86 linjer inkl. duplikat summary); ~15 unike `.cshtml`-filer.
8. **⚠️ Application Insights ikke konfigurert** — ingen `APPINSIGHTS_*` i App Settings; Serilog default only.
9. **⚠️ Ingen CDN/WAF** — DNS `www` → direkte `*.azurewebsites.net`; ingen Front Door/CDN i `rg-lunchportalen-prod`.
10. **✅ Custom domain TLS** — `lunchportalen.no` + `www.lunchportalen.no` SniEnabled med managed thumbprints.
